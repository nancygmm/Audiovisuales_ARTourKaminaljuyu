# Contenido Audiovisual para el AR Tour Kaminaljuyú para dispositivos iOS

## Diseño y desarrollo de un guía virtual interactivo con animación y audio con realidad aumentada mediante una aplicación móvil iOS para el Parque Arqueológico Kaminaljuyú.


En este repositorio se encuentran las carpetas con el contenido audiovisual que se utilizó para dicho proyecto, adicionalmente se encuentra también un documento que contiene el díalogo utilizado para describir cada punto de interés y también un excel donde se tiene un recuento de tiempo por audio/video para realizar el cálculo de los costos para dichas plataformas.

Los audios se encuentran ordenados en carpetas diferentes ya que se implementó en Español y en inglés, asimismo para los videos. Las plataformas utilizadas para esto fueron:

- ElevenLabs para los audios: https://elevenlabs.io/app/speech-synthesis/text-to-speech

- InfiniteTalk para animar el personaje con el audio incluido: https://www.infinitetalk.net/infinitetalk
